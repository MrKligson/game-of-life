# game-of-life

Conway's Game of life in [Godot](https://godotengine.org/).

## Build:
- Download and run [Godot](https://godotengine.org/)
- Click the "Import" button
- Select the folder containing this repo and press "Select this folder"
- Make sure "Edit now" is toggled on and press "Import"

This should add the project to your list of projects and open it for editing.
Press the F5-key to run it in a debug session

## Use:
Hotkeys:
- space or e: toggle edit/run mode
- c: clear
- r: randomise
- F11 or f: toggle fullscreen
- q: quit

In edit mode:
- Left mousebutton: paint live cells
- Right mousebutton: paint dead cells
